⚡ QUICK SETUP (10 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Extract this ZIP file

STEP 2: Open terminal/command prompt in project folder

STEP 3: Create virtual environment
   python -m venv .venv

STEP 4: Activate virtual environment
   WINDOWS: .venv\Scripts\activate
   MAC/LINUX: source .venv/bin/activate

STEP 5: Install dependencies
   pip install -r requirements.txt

STEP 6: Create MySQL database
   mysql -u root -e "CREATE DATABASE perfume_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
   
   (If MySQL password set, use: mysql -u root -p)

STEP 7: Navigate to Django folder
   cd perfume_platform

STEP 8: Run migrations
   python manage.py migrate

STEP 9: Create admin user
   python manage.py createsuperuser
   
   Username: admin
   Email: admin@example.com
   Password: (create strong password)

STEP 10: Start server
   python manage.py runserver

STEP 11: Open browser
   http://127.0.0.1:8000
